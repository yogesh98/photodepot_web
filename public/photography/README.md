# Landing-page photography

The seven current landing-page photographs were curated from Pexels. Photographer
credits, source pages, and processing details are documented in
[pexels/README.md](pexels/README.md). The Daylight homepage uses the catalogue in
`components/landing/photography.ts` for its six hero photographs and the team
photograph in the collaboration section. Each photograph has a visible
photographer credit linking to its Pexels source.

The original desktop application screenshots remain unretouched; their demo
photography is documented in [../screenshots/README.md](../screenshots/README.md).
